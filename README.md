Problem Statement
Title: Machine Learning-Based Pesticide Usage Prediction and Analysis

The excessive and improper use of pesticides in agriculture can lead to environmental pollution, soil degradation, water contamination and risks to human health. Understanding pesticide usage patterns across different countries, regions and years is important for promoting sustainable agricultural practices.

However, analysing large amounts of historical pesticide usage data manually makes it difficult to identify trends and predict future usage patterns accurately.

This project aims to develop a Machine Learning-Based Pesticide Usage Prediction System using historical agricultural data. The system analyses factors such as geographical area, pesticide category and year to predict pesticide usage. Different machine learning regression algorithms, including Linear Regression, Decision Tree Regression and Random Forest Regression, are implemented and compared using evaluation metrics such as MAE, MSE, RMSE and R² score.

The proposed system helps identify pesticide usage patterns, understand historical trends and support better agricultural planning and pesticide management.
Objectives
1. To collect and analyse historical pesticide usage data.
2. To preprocess the dataset and handle missing values.
3. To identify pesticide usage patterns across different regions and years.
4. To implement Linear Regression, Decision Tree and Random Forest algorithms.
5. To predict pesticide usage based on historical data.
6. To compare model performance using evaluation metrics.
7. To identify the best-performing machine learning model.
Expected Outcome
The project is expected to develop a machine learning model that predicts pesticide usage based on historical data and provides insights into pesticide consumption patterns.
